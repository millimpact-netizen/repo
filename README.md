# Sistema Virtual de Monedas para Padres e Hijos

## Problema
Actualmente, muchos niños no tienen una motivación constante para cumplir sus responsabilidades en casa, como ordenar su habitación, hacer los deberes, leer o ayudar con las tareas del hogar. Además, no existe un sistema sencillo y divertido que permita a los padres reconocer estos esfuerzos y recompensar a sus hijos de manera organizada.

## Solución
Se desarrollará una aplicación web llamada "Mi Tiendita de Recompensas", donde los padres podrán asignar monedas virtuales a sus hijos por cumplir actividades y responsabilidades.

Los niños tendrán una cuenta personal donde podrán consultar sus monedas acumuladas, visitar una tienda virtual y solicitar premios que sus padres hayan publicado, como juguetes, golosinas, salidas familiares, tiempo para videojuegos u otras recompensas.
Los padres podrán aprobar o rechazar las solicitudes y administrar las monedas de cada hijo. De esta manera, se busca fomentar la responsabilidad, el esfuerzo, la motivación y el hábito del ahorro desde pequeños.

## Objetivos
- 1. Desarrollar una aplicación web adaptable a computadoras y celulares, permitiendo que los usuarios accedan a sus funciones principales desde ambos dispositivos.
- 2. Implementar un sistema de registro e inicio de sesión que permita a un padre crear su cuenta e ingresar correctamente utilizando su correo electrónico y contraseña.
- 3. Crear al menos dos perfiles de hijos, permitiendo que cada uno consulte su nombre y saldo de monedas sin visualizar la información del otro.
- 4. Implementar la asignación de monedas virtuales, permitiendo que el padre seleccione un hijo, ingrese una cantidad y compruebe que el saldo de ese hijo aumente exactamente en la cantidad asignada.
- 5. Desarrollar una billetera digital que permita a cada hijo consultar su saldo actual y visualizar al menos los últimos cinco movimientos de monedas realizados.
- 6. Crear una tienda virtual que muestre al menos tres recompensas disponibles, incluyendo el nombre, descripción y precio de cada premio.
- 7. Implementar un sistema de solicitudes que permita al hijo seleccionar una recompensa y comprobar que esta aparezca como pendiente en el panel de sus padres.
- 8. Desarrollar un módulo de aprobación y rechazo de recompensas que permita al padre gestionar las solicitudes y visualizar el estado actualizado de cada una.
- 9. Implementar el descuento automático de monedas al aprobar una recompensa, comprobando que el saldo disminuya exactamente según el precio del premio y que no se permitan compras sin saldo suficiente.
- 10. Crear un historial de operaciones que permita consultar al menos diez movimientos registrados, identificando el tipo de operación, la cantidad de monedas y la fecha correspondiente.
- 11. Realizar pruebas funcionales con al menos un padre y dos hijos, verificando satisfactoriamente los procesos de registro, asignación de monedas, consulta de saldo y canje de recompensas.

Tienda virtual con recompensas personalizables.

Descuento automático de monedas cuando se apruebe un premio.
Historial básico de monedas y recompensas.

## Restricciones
- La primera versión estará enfocada en una sola familia.
- Los padres serán los administradores de las cuentas familiares.
- Las monedas serán completamente virtuales y no tendrán valor monetario real.
- Los premios serán definidos y proporcionados por los padres.
- No se incluirán pagos reales ni compras dentro de la aplicación.
- La aprobación de recompensas dependerá exclusivamente de los padres.
- Se desarrollará inicialmente como una aplicación web adaptable a celulares y computadoras.
- Se priorizarán las funciones principales antes de agregar características avanzadas.
- El sistema se desarrollará utilizando PHP 8, MySQL, HTML5, CSS3 y JavaScript.
- Se utilizará XAMPP como entorno de desarrollo y servidor local.
- La aplicación se probará inicialmente en Google Chrome.
- La base de datos se administrará mediante phpMyAdmin.
- El proyecto se desarrollará utilizando Visual Studio Code.
- No se implementará almacenamiento de dinero real ni pasarelas de pago.
- La aplicación estará diseñada para funcionar en navegadores de computadoras y celulares.
- Se priorizará el uso de herramientas gratuitas y de fácil acceso.
- El desarrollo se realizará por etapas, comenzando por el registro de usuarios y la administración de monedas.
